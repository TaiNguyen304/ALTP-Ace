Host Information free text → hostinformationDiv

Sends instantly as you'd expect from a live cue — press Send to Host (or Ctrl/Cmd+Enter in the box) and it appears in .infoTd on the engine page. Clear wipes the message from the display. Lock Panel disables every key button and stops keystrokes from triggering cues, so letters like A/C/F/S/W type normally instead of firing lifelines. Focusing the textarea locks automatically; it unlocks when you click away or press Lock again.
Every key button writes to localStorage['sharedKeyEvent'] — the exact same channel your existing window.addEventListener('storage', …) listener already consumes, so no changes are needed on the game engine page for those. Open this panel in its own tab/window alongside the controller page and keep both on the same origin (localStorage is per-origin).

The Host Information box is a new channel, localStorage['hostInfoMessage'], that your engine page doesn't listen for yet. Add this once, anywhere your other storage listeners live: 
window.addEventListener("storage", function(e) {
    if (e.key === "hostInfoMessage") {
        const data = JSON.parse(e.newValue);
        $('.hostinformationDiv .infoTd').text(data.text);
    }
});
That's it — whatever you type and send appears in .infoTd immediately, and Clear wipes it.
